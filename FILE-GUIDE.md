## 📋 Template Files (Your Starting Point)

### Primary Templates

#### `story-template.md`
- **Purpose**: Simple, beginner-friendly story input template
- **Best for**: First-time users, straightforward stories
- **Content**: Guided prompts for characters, plot, setting
- **Output**: Basic story website with standard features

#### `copilot-story-conversion-prompt.md`
- **Purpose**: Comprehensive template with technical specifications
- **Best for**: Professional sites, complex stories, experienced users
- **Content**: Detailed story structure + complete technical requirements
- **Output**: Production-ready site with custom styling and deployment

#### `example-story-conversion.md`
- **Purpose**: Complete example showing how to fill out templates
- **Story**: "The Midnight Garden" - Victorian gothic romance
- **Content**: Fully completed template as reference
- **Use**: Learn the format before creating your own

### Support Files

#### `QUICK-START.md`
- **Purpose**: Step-by-step guide to create your first story site
- **Content**: 5-minute setup process, troubleshooting, pro tips
- **Includes**: Template comparison, customization options

#### `prompts.md` (Generated)
- **Purpose**: AI image generation prompts for story illustrations
- **Content**: Chapter headers, character portraits, social cards
- **Note**: Auto-generated by Copilot, gitignored for privacy

## 🔧 How It All Works Together

### Story Creation Flow
1. **Fill Template** → Choose template, add story details
2. **Copilot Generation** → AI creates all content and code
3. **Customization** → Adjust colors, styling, images
4. **Deployment** → Push to GitHub, auto-deploy to web

### File Dependencies
```
Templates → Copilot → Story Markdown Files
                  ↓
Configuration ← Content → Navigation
     ↓              ↓          ↓
Styling ←→ Components ←→ Images
     ↓              ↓          ↓
     Build Process → Static Site
             ↓
     GitHub Actions → Live Website
```

### Customization Points
- **Colors**: CSS variables in `custom.css`
- **Layout**: React components in `src/components/`
- **Content**: Markdown files in `docs/`
- **Images**: Generated or custom in `static/img/`
- **Navigation**: Structure in `sidebars.js`

### New Story Creation
1. Start with appropriate template

5. Deploy to GitHub Pages

### Existing Story Conversion
1. Use advanced template for technical specs

1. Create separate repositories per story
2. Use consistent styling across sites

## 💡 Pro Tips

### Template Usage
- **More detail = better output**: Don't skip optional sections
- **Include examples**: Reference scenes or books you like
- **Specify style**: Tone, pacing, dialogue preferences
- **Plan structure**: Know your beginning, middle, end

### Customization
- **Start small**: Change colors first, then layout
- **Test mobile**: Most readers use phones/tablets
- **Optimize images**: Large images slow down sites
- **Check navigation**: Ensure logical reading flow

### Deployment
- **Use branches**: Test changes before main deployment
- **Monitor performance**: Check Google PageSpeed Insights
- **SEO optimize**: Add meta descriptions, alt text
- **Social preview**: Test how links appear when shared
