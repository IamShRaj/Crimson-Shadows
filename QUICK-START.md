# Quick Start Guide: Creating Your Story Site with Copilot

> **Transform any story idea into a professional gothic romance website in minutes using GitHub Copilot and our comprehensive templates.**

---

## 🚀 Quick Start (5 Minutes)

### Step 1: Choose Your Template
- **For beginners**: Use `story-template.md` (simpler, guided format)
- **For detailed stories**: Use `copilot-story-conversion-prompt.md` (comprehensive with technical specs)
- **For examples**: Look at `example-story-conversion.md` to see a filled-out template

### Step 2: Fill Out Your Story Idea
Open your chosen template and replace all the bracketed placeholders with your story details:
- Story title and genre
- Main characters with backgrounds
- Plot outline and key mysteries
- Setting and atmosphere
- Themes and style preferences

### Step 3: Generate Your Site
1. Copy the entire filled template
2. Open GitHub Copilot Chat in VS Code
3. Paste the template and add: 
   ```
   "Convert this story idea into a complete Docusaurus story website following all specifications. Generate all files, code, and content needed."
   ```

### Step 4: Deploy
Once Copilot generates your files:
1. Commit to GitHub
2. Enable GitHub Pages in repository settings
3. Your site will auto-deploy via GitHub Actions

## 🎨 Customization Options

## 💡 Pro Tips

### For Better Results
1. **Be Specific**: The more detail you provide, the better the output
2. **Include Atmosphere**: Describe mood, imagery, and sensory details
3. **Character Depth**: Give characters clear motivations and flaws
4. **Plot Structure**: Outline key turning points and revelations
5. **Theme Integration**: Specify how themes should appear in the story

### Prompt Optimization
- **Add Examples**: Reference scenes or books you want to emulate
- **Specify Style**: Mention pacing, dialogue style, description level
- **Include Constraints**: Word count preferences, content ratings
- **Request Extras**: Ask for specific scenes or character moments

### After Generation
- **Review Carefully**: Check for consistency and flow
- **Test Navigation**: Ensure all links work properly
- **Customize Styling**: Adjust colors and fonts to match your vision
- **Add Images**: Use the generated AI prompts to create visuals

## 🔧 Troubleshooting

### Common Issues
- **Broken Navigation**: Check `sidebars.js` for correct file paths
- **Styling Problems**: Verify CSS syntax in `custom.css`
- **Deployment Failures**: Check GitHub Actions logs for errors
- **Missing Images**: Ensure all image files are in the `static/img/` folder

### Getting Help
- **Documentation**: Check the Docusaurus docs for technical issues
- **Examples**: Look at the "Crimson Shadows" implementation for reference
- **Community**: Docusaurus and GitHub communities for support
