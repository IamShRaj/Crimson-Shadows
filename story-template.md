## Conversion Instructions for Copilot

**When converting this template into a full story, please:**

1. **Structure**: Create a prologue, 15+ chapters, and an epilogue similar to "Crimson Shadows"
2. **Style**: Use rich, atmospheric prose with gothic romance elements
3. **Character Development**: Show character growth through their actions and internal conflicts
4. **Pacing**: Build tension gradually while developing the romance
5. **Descriptions**: Include vivid, sensory descriptions that create atmosphere
6. **Dialogue**: Make conversations feel natural but with period/genre-appropriate flavor
7. **Chapter Endings**: End each chapter with hooks that make readers want to continue
8. **Themes**: Weave the specified themes throughout the narrative naturally
9. **Setting**: Use the environment as a character itself, reflecting the mood and themes

**Additional Features to Include:**
- Character profile pages (like the ones in Crimson Shadows)
- Timeline of events
- Story outline/summary
- Chapter-by-chapter breakdown with brief descriptions

**Output Format**: 
- Individual markdown files for each chapter
- Proper Docusaurus-compatible frontmatter
- Navigation structure for easy reading
- Character and world-building supplementary materials
